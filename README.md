# 결혼식 사회 대본 스킬 _by_mc_hyunjun

식순표 한 장만 주면 결혼식 사회 대본을 바로 써 주는 Claude 스킬입니다.
2015년부터 결혼식 사회를 봐 온 전문 사회자 **김현준**의 실제 대본 11편(2015~2026)과, 현장에서 직접 고친 최종본을 분석해 만들었습니다.

## 무엇을 해 주나요

- 식순표(사진·HWP·docx·텍스트)를 읽고 순서마다 읽을 대본을 씁니다.
- 필요한 것만 하나씩 물어봅니다. 언제든 "지금 바로 써줘"를 누르면 그때까지의 정보로 씁니다.
- 결과물은 바로 인쇄할 수 있는 `.docx`입니다.
  - 표 3칸: 진행순서 | 진행대본 | 비고(현장 메모)
  - 맨 위 총 소요시간 자동 계산
  - 구령·이름·날짜는 굵게, 무대지시는 파란색, 확인할 곳은 노란 형광
- 예식 지역·계절·두 사람 이야기 중 하나를 **컨셉**으로 잡아 처음부터 끝까지 이어 줍니다.
- 가족 사정처럼 조심스러운 이야기는 본문에 넣지 않고 비고 칸에만 적어 둡니다.

## 폴더 구성

| 파일 | 설명 |
|---|---|
| `SKILL.md` | 스킬 본체 (대본 규칙, 고정 문장, 작성법, 검수 목록) |
| `questionnaire.md` | 사회자용 문답지 + 신랑·신부에게 보내는 질문지 |
| `scripts/build_script_docx.py` | 대본 JSON → docx 생성 |
| `scripts/hwp2txt.py` | HWP 식순표·대본 텍스트 추출 |

## 쓰는 법

1. 이 폴더를 Claude 스킬로 추가합니다. (폴더를 zip으로 묶어 Claude의 스킬 추가 메뉴에 올리거나, Claude Code라면 `~/.claude/skills/` 아래에 폴더째 넣습니다.)
2. Claude에게 "결혼식 사회 대본 써줘"라고 하고 식순표를 첨부합니다.
3. 질문에 답하거나, `questionnaire.md`를 채워서 한 번에 붙여넣습니다.

## 다른 사회자가 쓸 때

`SKILL.md` 맨 위 **0. 설정**의 사회자 이름만 바꾸면 됩니다. 말투와 고정 문장은 김현준 사회자 스타일이니, 본인 대본에 맞게 5장(고정 문장)을 고쳐 쓰셔도 좋습니다.
